1b · Evaluation Finding — Faithfulness 높으나 완전히 틀린 답변 (faithfulness-but-wrong)

대표 실패: 자동 롤백 조건은? → retrieved 경비 청구 가이드(식대 1인 3만원 …) → faithfulness 1.0 but completely wrong. faithfulness는 grounding만 측정하므로 검색이 틀리면 완벽히 근거 있으나 완전히 틀린 답이 나온다. faithfulness alone is insufficient — retrieval relevance(context_precision/recall)와 answer correctness(Hit@5)를 별도 추적해야 한다. 전체 분석은 docs/evaluation_failure_analysis.md 참조 — out/ragas_result.json:13-20 (자동 롤백 faith 1.0, recall 0.2 vs gold 09_devops_deploy: Automatic rollback if error rate >5% for 5 minutes (Prometheus alert)), out/ragas_result.json:319-326 (환경 프로모션 faith 1.0, recall 0.066) — 2~3 examples, 재현은 python -m eval.ragas_eval --output out/ragas_result.json + python scripts/compare_rag.py 로 out/baseline_metrics.json vs out/improved_metrics.json 비교. Repair: LangGraph rewrite node + query expansion(자동 롤백 → Prometheus + error rate 5% + Helm).

perplexity note: 3 of 50 samples with faithfulness 1.0 have recall <0.3 — faithfulness cannot distinguish correct from wrong without recall. See also docs/evaluation_failure_analysis.md Appendix A (rg "Automatic rollback 5% for 5 minutes" / "식대 1인 3만원").
