# Reproducibility Guide — rag-ops-console (Online RAG)

> RAGAS Before/After (measured): `context_precision 0.3666→0.42`, `context_recall 0.6133→0.627`, `faithfulness 0.9934→0.9953` (50 samples, `eval/ragas_eval.py` deterministic fallback, plus optional `ragas` library path). Historical recorded baseline `0.3102/0.512/0.971` (2026-08-22, hash, no rerank) not reproduced on current synthetic (10 chunks) — see `out/baseline_historical_reference.json` and `out/repro_investigation.md`.
> Sources: `out/baseline_metrics.json` (measured hash, `RAG_EMBEDDING_MODEL=hash RAG_DISABLE_RERANK=1`), `out/improved_metrics.json` (multilingual+rerank), `out/ragas_result.json`, `out/ops_rag.log`, `data/synthetic_qa.jsonl`, `eval/ragas_eval.py`, `rag/vector_store.py`, `graph/run.py`

## 1. File Structure (Before/After)

```
out/
├── baseline_metrics.json     # from metrics_report.json / before snapshot (hash-embedding, no rerank, no rewrite)
├── improved_metrics.json     # after fixes — e.g., sentence-transformers + keyword rerank + rewrite 1회
└── comparison.md             # generated by python scripts/compare_rag.py
```

Canonical pattern:

- **Before (measured, current repro)** (`out/baseline_metrics.json`): `avg_context_precision 0.3666, avg_context_recall 0.6133, avg_faithfulness 0.9934` — hash embedding (`RAG_EMBEDDING_MODEL=hash`) + rerank disabled (`RAG_DISABLE_RERANK=1`), 50 samples, see `out/repro_investigation.md` §2.
- **Historical recorded baseline** (`out/baseline_historical_reference.json`): `avg_context_precision 0.31, avg_context_recall 0.512, avg_faithfulness 0.971` (hash-embedding baseline, 2026-08-22, historical record — exact env not reproduced on current synthetic 10 chunks, preserved with `historical_recorded_baseline` flag).
- **After** (`out/improved_metrics.json` or current `out/ragas_result.json`): `avg_context_precision 0.42, avg_context_recall 0.627, avg_faithfulness 0.9953` (`out/ragas_result.json:454-459`, sentence-transformers multilingual + keyword rerank +0.1 + rewrite 1회).

In this repo `out/ragas_result.json` itself is the After snapshot (50 samples). To create a Before snapshot before rerunning:

```bash
Copy-Item out/ragas_result.json out/baseline_ragas_result.json   # Windows
# cp out/ragas_result.json out/baseline_ragas_result.json        # macOS/Linux
# then also snapshot aggregate as baseline_metrics.json if needed:
Copy-Item out/ragas_result.json out/baseline_metrics.json
```

After applying fixes, new run writes `out/ragas_result.json` (or `out/improved_metrics.json`); `scripts/compare_rag.py` diffs them.

## 2. One-Command Reproduction

### 2.1 RAGAS evaluation (50 samples, deterministic fallback)

```bash
# Full repro — VectorDB ingest (10 chunks, Chroma PersistentClient, dedup skip) + retrieve top_k=3 + RAGAS
python -m eval.ragas_eval --output out/ragas_result.json
python -m eval.ragas_eval --output out/ragas_result.json --top-k 3
python -m eval.ragas_eval --input data/synthetic_qa.jsonl --output out/ragas_result.json --top-k 3

# Inspect
Get-Content out/ragas_result.json | Select-Object -First 40
Get-Content out/ragas_result.json | Select-String "avg_context_precision|avg_context_recall|avg_faithfulness"
```

`eval/ragas_eval.py` tries `ragas.metrics.{context_precision,context_recall,faithfulness}` + `ragas.evaluate` + `datasets.Dataset` if LLM keys are set; otherwise the deterministic token-overlap fallback produces the recorded `0.42/0.627/0.9953` (see `eval/ragas_eval.py:55-129`).

### 2.2 Retrieval log reproduce

```bash
python -m rag.vector_store --help
python -m graph.run --query "환불 정책"   # writes out/ops_rag.log canonical trace (if CLI exposed)
Get-Content out/ops_rag.log               # lines 1-14: retrieve 5 chunks, grade relevant, generate 470, overlap 0.89
Get-Content out/ops_rag.log | Select-String "\[retrieve\]|\[grade\]|\[human_review\]"
```

Canonical log: `[retrieve] found 5 chunks` with `07_customer_support::chunk-0000 score=0.357 rerank=0.457` (`out/ops_rag.log:6`), `threshold_score=0.25` (`out/ops_rag.log:9`), `[human_review] token overlap ratio=0.89 -> approved` (`out/ops_rag.log:13-14`).

### 2.3 Comparison (baseline vs improved)

```bash
# baseline vs improved markdown table
python scripts/compare_rag.py --baseline out/baseline_metrics.json --improved out/improved_metrics.json
python scripts/compare_rag.py --baseline out/baseline_ragas_result.json --improved out/ragas_result.json
# default (auto-discovers)
python scripts/compare_rag.py
Get-Content out/comparison.md
```

`scripts/compare_rag.py` loads the two JSONs (supports both `aggregate` RAGAS shape and flat metrics shape), prints a markdown table with Δ and percent change, and writes `out/comparison.md`. If not yet implemented, this doc is the spec + TODO (minimal loader).

### 2.4 Faithfulness-but-wrong targeted repro

```bash
# single failing query — verify faithfulness high but recall low
Get-Content out/ragas_result.json | Select-String "자동 롤백|환경 프로모션|경비 청구"
python -m eval.ragas_eval --output out/ragas_result.json
Get-Content out/ragas_result.json | Select-String '"question": "자동 롤백' -Context 0,5
# expected: faithfulness 1.0, context_recall 0.2, generation is finance guide (10_finance_expense)
```

See `docs/evaluation_failure_analysis.md` (§1, Appendix A) for `rg "Automatic rollback 5% for 5 minutes"` vs `rg "식대 1인 3만원"` reproduction.
