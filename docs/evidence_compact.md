## Repro commands (1-command each)

```bash
# Improved — deterministic RAGAS (multilingual+rerank, default)
python -m eval.ragas_eval --output out/ragas_result.json
python -m eval.ragas_eval --output out/improved_metrics.json

# Baseline measured — hash embedding, rerank disabled (yields 0.3666)
RAG_EMBEDDING_MODEL=hash RAG_DISABLE_RERANK=1 python -m eval.ragas_eval --output out/baseline_metrics.json
# Windows PowerShell:
$env:RAG_EMBEDDING_MODEL="hash"; $env:RAG_DISABLE_RERANK="1"; python -m eval.ragas_eval --output out/baseline_metrics.json

# Comparison (fail-closed — exits 2 if files missing/same/no metrics)
python scripts/compare_rag.py --baseline out/baseline_metrics.json --improved out/improved_metrics.json
Get-Content out/comparison.md
```
